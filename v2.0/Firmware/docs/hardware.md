# ハードウェア対応表

Gate Sequencer V2 基板（CH32V003F4U6）のピン割り当てと、74HC595 / 74HC165 チェーンのビット配置です。
KiCad の PCB ファイル（パッドとネットの対応）から抽出しました。
ファームでは `src/hal_ch32.c`（ピン）と `src/io_map.c`（ビット配置・スイッチの判定）が、この表に対応します。

## MCU ピン

括弧内は QFN-20 のパッケージピン番号です。

| 機能 | CH32V003F4U6 | 備考 |
|---|---|---|
| CLK 入力 | PD0（5） | トランジスタで反転。EXTI0 |
| IN A | PD2（16） | 反転。EXTI2 |
| IN B | PD3（17） | 反転。EXTI3 |
| IN C | PD4（18） | 反転。EXTI4 |
| PAUSE | PA1（2） | 反転。EXTI1 |
| TRIG A 出力 | PC3（10） | 1kΩ 経由で直接駆動 |
| TRIG B 出力 | PC4（11） | 同上 |
| 595 SER | PC6（13）SPI MOSI | 47Ω 直列 |
| 595 SRCLK | PC5（12）SPI SCK | 165 の CP と共用 |
| 595 RCLK | PC1（8） | 47Ω 直列 |
| 165 Q7 | PC7（14）SPI MISO | 47Ω 直列 |
| 165 SH/LD | PC2（9） | 47Ω 直列 |
| 165 CLK | PC5（12）SPI SCK | 595 と共用 |
| パネル LED CLK/A/B/C | 595 U12 の QB / QC / QD / QE | |
| パネル LED PAUSE / OUT_A / OUT_B | 595 U12 の QF / QG / QH | |
| 乱数シード | PA2（3）の ADC | PA2 は未接続 |
| SWIO | PD1（15） | WCH-LinkE |
| NRST | PD7（1） | リセットボタン SW23 |
| UART TX / RX | PD5（19）/ PD6（20） | 1kΩ 経由でヘッダ J25 |
| 未使用 | PC0（7） | |

- 直結入力（CLK / IN A〜C / PAUSE）はトランジスタで反転しています。ジャックが HIGH のとき、ピンは LOW になります

## 595 チェーン（出力）

- 5 個（40bit）。MOSI → U3 → U5 → U8 → U10 → U12 の順に並びます
- 表の `n*8+b` は「n バイト目の bit b」を表します
  - byte0 を最初に送り、チェーン末端の IC（U12）に入ります
  - 各バイトは MSB first で、bit b が Q(A+b) に出ます

| ch | OUT | ステップ LED |
|---|---|---|
| 1 | 4*8+2（U3.QC） | 4*8+1（U3.QB） |
| 2 | 4*8+4（U3.QE） | 4*8+3（U3.QD） |
| 3 | 3*8+2（U5.QC） | 3*8+1（U5.QB） |
| 4 | 3*8+4（U5.QE） | 3*8+3（U5.QD） |
| 5 | 2*8+2（U8.QC） | 2*8+1（U8.QB） |
| 6 | 2*8+4（U8.QE） | 2*8+3（U8.QD） |
| 7 | 1*8+2（U10.QC） | 1*8+1（U10.QB） |
| 8 | 1*8+4（U10.QE） | 1*8+3（U10.QD） |
| 9 | 4*8+6（U3.QG） | 4*8+5（U3.QF） |
| 10 | 4*8+7（U3.QH） | 4*8+0（U3.QA） |
| 11 | 3*8+6（U5.QG） | 3*8+5（U5.QF） |
| 12 | 3*8+7（U5.QH） | 3*8+0（U5.QA） |
| 13 | 2*8+6（U8.QG） | 2*8+5（U8.QF） |
| 14 | 2*8+7（U8.QH） | 2*8+0（U8.QA） |
| 15 | 1*8+6（U10.QG） | 1*8+5（U10.QF） |
| 16 | 1*8+7（U10.QH） | 1*8+0（U10.QA） |

パネル LED（byte0 = U12）:

| LED | 表示内容 | bit |
|---|---|---|
| LED_A | CLK | 0*8+1（U12.QB） |
| LED_B | A | 0*8+2（U12.QC） |
| LED_C | B | 0*8+3（U12.QD） |
| LED_D | C | 0*8+4（U12.QE） |
| LED_E | PAUSE | 0*8+5（U12.QF） |
| LED_F | OUT_A（TRIG A） | 0*8+6（U12.QG） |
| LED_G | OUT_B（TRIG B） | 0*8+7（U12.QH） |
| — | 未使用 | 0*8+0（U12.QA） |

## 165 チェーン（入力）

- U2 → U4 → U7 → U9 → U11 → MCU の順に並びます
- 最初に読むバイトが byte0（MCU に最も近い U11）です。各バイトは MSB first で、Dn が bit n になります
- 入力はすべて 5V / 12kΩ でプルアップしています。接点が GND に落ちると LOW になります

| SW | A 接点 | B 接点 |
|---|---|---|
| SW1 | 4*8+4（U2.D4） | 4*8+5（U2.D5） |
| SW2 | 4*8+3（U2.D3） | 4*8+2（U2.D2） |
| SW3 | 3*8+4（U4.D4） | 3*8+5（U4.D5） |
| SW4 | 3*8+3（U4.D3） | 3*8+2（U4.D2） |
| SW5 | 2*8+4（U7.D4） | 2*8+5（U7.D5） |
| SW6 | 2*8+3（U7.D3） | 2*8+2（U7.D2） |
| SW7 | 1*8+4（U9.D4） | 1*8+5（U9.D5） |
| SW8 | 1*8+3（U9.D3） | 1*8+2（U9.D2） |
| SW9 | 4*8+6（U2.D6） | 4*8+7（U2.D7） |
| SW10 | 4*8+1（U2.D1） | 4*8+0（U2.D0） |
| SW11 | 3*8+6（U4.D6） | 3*8+7（U4.D7） |
| SW12 | 3*8+1（U4.D1） | 3*8+0（U4.D0） |
| SW13 | 2*8+6（U7.D6） | 2*8+7（U7.D7） |
| SW14 | 2*8+1（U7.D1） | 2*8+0（U7.D0） |
| SW15 | 1*8+6（U9.D6） | 1*8+7（U9.D7） |

| SW17 | 0*8+3（U11.D3） | 0*8+2（U11.D2） |
| SW18 | 0*8+1（U11.D1） | 0*8+0（U11.D0） |

| Push | bit |
|---|---|
| Push_CLK | 0*8+7（U11.D7） |

| Push_B | 0*8+5（U11.D5） |

- Push は押すと LOW になります

## トグルスイッチの判定

| 物理位置 | A 接点 | B 接点 | 値（`enum SwPos`） |
|---|---|---|---|
| 左 | HIGH | LOW | 0（`SW_LEFT`） |
| センター | HIGH | HIGH | 1（`SW_CENTER`） |
| 右 | LOW | HIGH | 2（`SW_RIGHT`） |

- A・B が両方 LOW になる異常時は、センターとして扱います
- SW17 は方向（左 = Forward、センター = PingPong、右 = Random）、SW18 はモード（左 = MODE 1、センター = MODE 2、右 = MODE 3）です
