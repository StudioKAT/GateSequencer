# Gate Sequencer Firmware

RP2040-Zeroを使用したGate Sequencerモジュールのファームウェアです。
3つの動作モード（Dual 8-step / 16-step / Shift Register）を備えています。

## ファームウェア書き込み手順 (RP2040-Zero)

このモジュールは **RP2040-Zero** マイコンを使用しています。以下の手順で `.uf2` ファイルを書き込んでください。

### 準備するもの
* PC (Windows / Mac / Linux)
* USBケーブル (Type-C)
* コンパイル済みの `.uf2` ファイル

### 書き込みステップ

1.  **USB接続 (ブートローダーモード)**
    RP2040-Zeroボード上の **BOOTボタン** を押しながら、PCとUSBケーブルで接続します。
    （または、接続状態でBOOTボタンを押しながらRESETボタンを押し、RESETを離してからBOOTを離します）

2.  **ドライブの認識**
    PC上に `RPI-RP2` という名前のリムーバブルドライブとして認識されます。

3.  **ファイルのコピー**
    コンパイルした `.uf2` ファイルを、`RPI-RP2` ドライブの中にドラッグ＆ドロップ（またはコピー＆ペースト）します。

4.  **完了**
    書き込みが完了するとドライブは自動的に切断され、RP2040-Zeroが再起動してGate Sequencerとして動作を開始します。

### トラブルシューティング
* `RPI-RP2` ドライブが表示されない場合は、USBケーブルがデータ通信対応か確認してください（充電専用ケーブルでは書き込めません）。
* 書き込み後に動作がおかしい場合は、一度USBを抜き、再度上記手順で書き込み直してください。

## v2.0 アップデート内容

### 1. コンフィグモード (設定機能) の追加
電源投入時の操作で、Gate出力の挙動を変更できるようになりました。設定は内部メモリ(Flash)に保存され、次回起動時も維持されます。

* **起動方法**: 電源投入時、**Push_CLK** と **Push_A** を同時に押し続けます。
* **設定項目 (Gate Output Mode)**:
    * **Mode A (Push_Bで選択)**: [デフォルト] 各ステップのGate出力は確率スイッチに関係なく、到達すれば常にHIGHになります（TRIG出力のみ確率に従う）。
    * **Mode B (Push_Cで選択)**: 各ステップのGate出力も確率スイッチ(OFF/PROB/ON)の影響を受けます。
* **保存と終了**:
    * **Push_CLK**: 設定を保存して再起動します。
    * **Push_A**: 保存せずに再起動します。

### 2. Mode 0 (Dual Sequencer) の状態保存
Mode 0における以下の設定状態がメモリに保存されるようになりました。電源を落としても前回の設定が復元されます。
* **Sync AB**: Seq BのクロックをSeq Aと同期するかどうか (Push_Aで切替)
* **Sync Reset**: Reset入力を同期するかどうか (Push_Cで切替)
