# Gate Sequencer
![Gate Sequencer Front](v2.0/Images/GateSequencer_v2.0_Front.jpg)

## 概要 / Overview

**Gate Sequencer** は、トグルスイッチ式の多機能ゲートシーケンサーです。   
・独立した2つのクロックで動く **8 Stepシーケンサー x2**  
・パフォーマンス機能を備えた **16 Stepシーケンサー**  
・可変長・経路変更可能な **シフトレジスタ (Turing Machine)**  
の3つの機能を備え、スイッチ一つで切り替えて使用できます。

**Gate Sequencer** is a multi-functional gate sequencer equipped with toggle switches. It features three distinct functions that can be switched via a single mode switch:
* **8-Step Sequencer x2** running on independent clocks.
* **16-Step Sequencer** with performance features.
* **Shift Register (Turing Machine)** with variable length and routing capabilities. 


## 仕様 / Spec
- Format: Eurorack
- Function: Gate Sequencer
- Current needs: +12V: 50mA, -12V: 0mA
- Width: 14 HP
- Depth: 25mm (including power connector)
